# Shopping-Mall-Logic
An advanced Object-Oriented Programming (OOP) project in Java that simulates a shopping mall billing and inventory system. It heavily utilizes core OOP principles including Abstraction, Inheritance, and Polymorphism. The system categorizes items into Foods and Clothings, dynamically applies category-specific VAT rates, calculates profit margins, and uses Java Interfaces (`Vegan`, `Washable`) to output item-specific instructions without breaking the core architecture.
